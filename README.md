# KICHONG.XYZ fire links

A reusable, full-screen personal links template built with React and Vite. It uses a living painterly flame, an evenly distributed moving orbit, a reusable custom SVG icon bank, muted YouTube autoplay controls, passwordless owner login, and an authenticated destination/media editor.

## Local development

```bash
npm install
npm run dev
```

The four example links work without a backend. Follow [SETUP.md](./SETUP.md) to enable persistent editing with Supabase and deploy the static frontend to Vercel.

## Commands

```bash
npm run lint
npm run build
```
